02设计理念 · 为何走哑光金属

反霓虹：哑光质感更耐看

目标站的荧光霓虹在长时间游戏时易视觉疲劳，且与"竞赛附加题"的严肃气质略有错位。哑光金属以低饱和、有重量感的表面，传达"装备"而非"特效"，契合坦克军武题材，也更显克制的高级。

反等宽：衬线标题 + 无衬线正文

目标站全程等宽字体配超大字距，偏"终端极客"。新方案用衬线（标题/数字）承担权威感与仪式感，无衬线承担可读正文，等宽仅用于真实数据/代号——三种字体各司其职，层次更分明。

反圆角玻璃：几何切角

目标站小圆角 + backdrop blur 是典型"玻璃态"。新方案改用 clip-path 切角，呈现装甲板的折面感，与坦克的多边形轮廓同构，强化主题而非套用通用 UI 风。

反多色霓虹：单一琥珀强调

目标站青/紫/红三色霓虹分散焦点。新方案只保留一个强调色——琥珀金，用于关键操作、当前状态、可交互反馈。视觉焦点收敛，信息层级更清晰。

05与目标站区隔对照
目标站 · 赛博朋克荧光
  • 深空炭黑 #040608 纯黑
  • 荧光青/紫/红三色霓虹
  • 单一等宽字体 + 6-12px 字距

  • 多层霓虹 box-shadow 光晕

  • 深海军蓝 #0B1220 带蓝调（非纯黑）
  • 单一琥珀强调，钢蓝辅助，无荧光
